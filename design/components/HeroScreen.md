# HeroScreen

The approved Library screen (H3 · Title 36, italic Books), reproduced exactly and annotated. Every other component is taken from it.

**Frame.** 390 × 844, base `bg-base`, six wash circles, 20px gutters. Content stack starts at y = 222.

**Top to bottom.**
1. **App header** at y = 50: title left, profile button right (y = 54).
2. **Hero count** at y = 100.
3. **White top zone**, from 0 to 404px: solid white to 282px, transparent by 394px. The reading card's lower half sits in the fade.
4. **Reading-now card** at y = 222, then 16px gaps (`stack`) to the **chips** and the **shelves**.
5. **Two shelf rows** of three covers, each with a glass ledge, 14px apart.
6. **Tab bar** floating 14px from the sides and 18px from the bottom.

Use this screen as the reference when building any new screen: same frame, same washes, same white zone, same rhythm.
