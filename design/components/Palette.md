# Palette

Every colour in BB's Books with the job it does. The interface is base, white, ink and glass. The washes give the colour, and cobalt is the single accent.

- **Cobalt is for marks, not paragraphs.** The scan button, progress fill, eyebrow and tab dots, and the profile icon. As text it only sits on white, base or the tint, never as small text on the washes (it drops to 3.9:1 on coral and pink).
- **Washes are only ever blurred circles** behind the content: blur 50px, 75–90% opacity. Never a flat fill on a component.
- **Tint, outline and solid ledge are the white-zone kit.** On pure white, glass reads grey, so chips switch to tint and ledges to solid.
- **Covers** use the six placeholder pairs only when no cover image exists. Pick one from the book's ID so it stays the same every time.
